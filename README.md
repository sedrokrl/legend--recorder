# 🎙 Legend Recorder — مود التسجيل داخل ماين كرافت (Fabric 1.21.1)

تسجيل **فيديو + شاشة + صوت** من داخل اللعبة مباشرة، بواجهة تشبه **Simple Voice Chat**،
مع **تحكم بالصوت** و**إزالة تشويش حقيقية** و**تحكم بالجودة** — ومصمم خصيصاً **بدون لاق**.

## ✨ المميزات
- 🔴 تسجيل داخل اللعبة: `R` للقائمة — `F9` للتسجيل السريع (مثل LegendRecorder.exe)
- 🪟 يصور **نافذة اللعبة فقط** تلقائياً (أخف من الشاشة الكاملة) أو الشاشة كاملة
- 🎚 تحكم: تضخيم المايك 0-200%، صوت اللاعبين 0-200%، كتم، إيقاف مؤقت
- 🔇 إزالة تشويش حقيقية (بدون مكتبات): DC Blocker + فلتر 80Hz + بوابة ضجيج تتعلم صوت مروحتك + مخفف وشيش + AGC + Limiter — بمستويات (بدون/خفيفة/قوية) + زر معايرة
- 🎞 جودة: 720p30 (خفيف) / 720p60 / 1080p30 / 1080p60 + ضغط JPEG قابل للضبط + **جودة تلقائية** تخفض FPS مؤقتاً عند الضغط
- 🗣 تكامل اختياري مع Simple Voice Chat (يعمل بدونه أيضاً — وضع مستقل)
- ⚡ منع اللاق: كل الالتقاط والترميز والصوت **بخيوط منفصلة**، طابور 6 فريمات مع إسقاط ذكي، أولوية أقل من اللعبة، مؤشر إحصائيات (FPS/مُسقط)
- 📁 الحفظ: `Videos/LegendRecorder/Legend_....avi` + `....wav` بجانبه (اسحبهما معاً في CapCut — مثل النسخة الخارجية)

## 🛠 التثبيت
1. ثبّت **Java 21** و **Fabric Loader 0.16.14** لماين كرافت **1.21.1** + **Fabric API**
2. (اختياري) ركّب **Simple Voice Chat** بإصدار فابرك 1.21.1
3. انسخ `legend-recorder-1.0.0.jar` إلى مجلد `mods`
4. شغّل اللعبة — اضغط **R**

## 🏗 البناء من المصدر (على جهازك)
المشروع كامل وجاهز — كل أرقام الإصدارات تم التحقق منها من مخازن Fabric الرسمية،
وكود الواجهة تمت مطابقته مع `yarn 1.21.1+build.3` وملف اللعبة الأصلي
(بما فيها تفاصيل دقيقة: مُنشئ `KeyBinding` الثلاثي، والرسم عبر `renderBackground`).

```bat
winget install Microsoft.OpenJDK.21
winget install Gradle.Gradle
cd C:\LegendRecorderMod
gradle build
```
الملف الناتج في `build\libs\legend-recorder-1.0.0.jar` — انسخه إلى مجلد `mods`.
يحتاج إنترنت أول مرة (تحميل yarn/mappings).

## ⚠️ ملاحظات مهمة
- **صوت اللعبة الداخلي** (وحوش/بلوكات): جافا النقية لا تستطيع التقاط صوت الويندوز مباشرة بدون تعريف — المود يسجل **المايك + أصوات لاعبي الفويس** بوضوح. لتسجيل كل صوت اللعبة فعّل **Stereo Mix** من إعدادات الصوت في ويندوز.
- **ملء الشاشة الحصري (Fullscreen: OFF)**: مثل النسخة الخارجية — استخدم نافذة مكبرة/Borderless حتى يلتقط نافذة اللعبة صح.
- أول 0.5 ثانية من كل تسجيل للمعايرة — **اسكت فيها** لأدق إزالة تشويش.
- إن رأيت "مُسقَط" يرتفع: انزل إلى 720p30 وقلل ضغط JPEG إلى 70 — لن يعلق أبداً بسبب الإسقاط الذكي.
